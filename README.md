# The Big League MFL Theme

Hosted design layer for **The Big League** on MyFantasyLeague (2026 league 73086).

## Purpose
MFL remains the league engine and source of truth for rosters, standings, transactions, scoring, waivers, and schedules. This repository hosts the visual layer so the league can use cleaner CSS, JavaScript, images, and test pages without stuffing everything into MFL custom messages.

## Structure
- `bigleague.css` — master visual theme
- `bigleague.js` — optional enhancements
- `index.html` — GitHub Pages test page
- `assets/` — banners, logos, backgrounds, and other static files

## Safety
The current working MFL Message #1 backup remains the rollback version while hosted files are tested.
